# 把 2D 形象包导入知令（用户手册）

本文档面向**知令桌宠用户**：如何把别人做好的 2D 形象包（`.zip` 或文件夹）装进知令，让桌宠用上自定义形象。

> 制作自己的资产包请阅读 [asset-pack-spec.md](asset-pack-spec.md)（作者手册）。

## 1. 资产放在哪里

知令把用户 2D 形象存放在数据根下的固定目录：

```text
<数据根>/pet_assets/2D_FRAMES/
└── user_2d_<id>/          # 每个导入成功的包一个目录
    ├── manifest.json
    ├── thumb.png
    ├── idle/ ...
    └── wave/ ...
```

- Windows 默认数据根：`C:\Users\<用户名>\.zhiling`；
- 可在「设置 → 常规 → 数据目录」把数据根改到其它位置（改动重启后生效），目录名 `pet_assets/2D_FRAMES` 保持不变。

## 2. 打开设置页并自动发现

1. 打开知令「设置」→「桌面宠物」（桌宠）设置卡；
2. 打开设置页时知令会自动：
   - 建立 `<数据根>/pet_assets/2D_FRAMES` 目录；
   - 扫描并列出已导入的 2D 帧形象；
   - 执行一次旧数据迁移（见第 5 节）。

## 3. 导入方式

设置卡上提供三个入口：

| 按钮 | 作用 |
|---|---|
| **导入 2D 帧包…** | 弹出文件选择框，选择单个 `.zip` 包导入（zip 根即形象，含 `manifest.json` + 帧） |
| **扫描资产库文件夹…** | 选择一个文件夹扫描，发现其中可导入的资产（zip 包、已解压的 2D 帧目录、3D VRM），列在「待导入」清单里，可**单项导入**或**导入全部** |
| **打开 2D 资产目录** | 在资源管理器中打开 `<数据根>/pet_assets/2D_FRAMES`，可手工放入/管理文件 |

导入成功的包会以 `user_2d_<id>` 命名落盘（`id` 取 manifest.id → name → 文件名，重名自动加 `_2`、`_3` 后缀；相同内容的包 sha256 去重，重复导入直接复用）。

**扫描清单条目**的类型与来源标识：

- 类型：`2D zip`（帧包 zip） / `2D 文件夹`（已解压目录） / `3D VRM`；
- 来源：`放置目录`（所选文件夹下的文件） / `资产库`（本仓库式 `assets/pet_seq/` 库结构中的形象目录，会自动合成 manifest）。

> 扫描资产库文件夹也支持直接选 `assets/pet_seq/whale_chibi` 这类目录：目录没有自己的 `manifest.json`，但父目录 `manifest.json` 的 `avatars[]` 里有对应条目，知令会按条目合成单形象包导入。

## 4. 导入后：选中与移除

- 导入成功后设置卡会自动刷新并**选中新形象**；也可以在形象卡片里手动切换；
- 运行时只播放 `idle`（循环）与 `wave`（单次）；包内其它动作只保存、不播放；
- 选中用户 2D 形象后，卡片右侧出现**移除**按钮，点击删除 `<数据根>/pet_assets/2D_FRAMES/user_2d_<id>/` 整个目录（仅 `user_2d_` 前缀的目录可移除，内置资产不受影响）。

## 5. 旧 `pet_models` 自动迁移

旧版知令把用户模型放在 `<数据根>/pet_models/<user_*>/`。现在打开设置页（宠物窗口注册时）会自动执行迁移：

- 把 `pet_models` 下的 `user_*` 目录移动到 `<数据根>/pet_assets/3D_VRMs/<同 id>/`；
- 只移动真实目录、不跟符号链接；目标已存在则跳过，绝不覆盖；
- 优先同卷 rename（瞬时），失败回退「复制 + 文件数/大小校验」后删源；
- 迁移只针对 **3D VRM 模型**（`3D_VRMs` 根）；2D 帧包目录 `2D_FRAMES` 与 3D 并列，从导入功能创建。

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 导入失败：`file_too_large` | 包超过限额（zip 128MB / 单文件 8MB / 总量 256MB），拆分或压缩素材 |
| 导入失败：`too_many_entries` | zip 条目超 2000 |
| 导入失败：`unsafe_entry` | 包内有 `.DS_Store` / `__MACOSX` / 绝对路径 / `..` / 非白名单文件（`.jpg` `.gif` 等），用 `tools/pack_2d_frames.py --pack` 重新打包 |
| 导入失败：`missing_manifest` / `invalid_manifest` | 缺少 `manifest.json` 或字段非法，见作者手册 |
| 导入失败：`missing_idle` / `invalid_frames` | 缺 `idle` 动作或帧命名不连续（`frame_000` 起、无缺号、同扩展名同位数） |
| 设置页看不到新形象 | 关闭重开设置页；确认目录在 `<数据根>/pet_assets/2D_FRAMES/` 且目录名以 `user_2d_` 开头 |
| 形象动不了 / 缺 wave | 包内 `idle` 必须 ≥2 帧；`wave` 缺失时桌宠只用 `idle`（回退安全） |
| 想恢复内置鲸鱼娘 | 在形象卡片里切回内置「Q 版鲸鱼娘（2D）」即可 |
| 缩略图不显示 | 包内无 `thumb.png` 且 `idle` 首帧不可用；补一个 `thumb.png` 重新导入 |

## 7. 示例包

本仓库 `examples/whale_chibi_demo.zip` 是合规示例（`idle` 35 帧 + `wave` 36 帧 + `thumb.png`），可直接用「导入 2D 帧包…」导入体验。
